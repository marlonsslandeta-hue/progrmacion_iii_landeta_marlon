📚 Descripción

Este repositorio contiene el material, ejercicios, prácticas y proyectos desarrollados durante la materia Programación III.

A lo largo del curso se estudiarán diferentes tecnologías orientadas al desarrollo web, comenzando desde los fundamentos de la construcción de páginas hasta el desarrollo de aplicaciones modernas con frontend y backend.

🧠 Tecnologías y conceptos
🌐 HTML

HTML (HyperText Markup Language) es el lenguaje utilizado para estructurar el contenido de una página web. Permite definir elementos como títulos, párrafos, imágenes, enlaces, formularios, tablas y diferentes secciones de un sitio web.

🎨 CSS

CSS (Cascading Style Sheets) se utiliza para dar estilo y presentación a las páginas web. Permite trabajar con colores, tipografías, tamaños, posiciones, diseños, animaciones y diseños adaptables a diferentes dispositivos.

⚡ JavaScript

JavaScript es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento dinámico a las páginas web. Permite manipular elementos HTML, responder a eventos, trabajar con datos y comunicarse con servicios externos mediante APIs.

📘 TypeScript

TypeScript es un lenguaje basado en JavaScript que incorpora tipado estático y otras funcionalidades que facilitan la creación y mantenimiento de aplicaciones de mayor tamaño. Es ampliamente utilizado en proyectos modernos de desarrollo web.

🚀 NestJS

NestJS es un framework para desarrollar aplicaciones backend utilizando Node.js y TypeScript. Su arquitectura permite crear aplicaciones organizadas, escalables y mantenibles, especialmente para el desarrollo de APIs y servicios web.

⚛️ ReactJS

ReactJS es una biblioteca de JavaScript utilizada para construir interfaces de usuario. Permite desarrollar aplicaciones web mediante componentes reutilizables y administrar de manera eficiente los cambios en la interfaz.

🗂️ Contenido del curso

Durante el desarrollo de la materia se trabajará con:

HTML y estructura de páginas web.

CSS y diseño de interfaces.

Fundamentos y programación con JavaScript.

TypeScript y tipado estático.

Desarrollo de APIs y backend con NestJS.

Desarrollo de interfaces y aplicaciones con ReactJS.

Integración entre frontend y backend.

Desarrollo de proyectos aplicando las tecnologías estudiadas.
